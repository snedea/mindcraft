## Useful Commands

### Check Andy's Status
```bash
# Container logs
cd ~/homelab/mindcraft && docker compose logs --tail=50

# Andy's position
docker exec minecraft-minecraft-1 rcon-cli "data get entity andy Pos"

# Give Andy items
docker exec minecraft-minecraft-1 rcon-cli "give andy diamond_pickaxe 1"

# Teleport Andy to spawn
docker exec minecraft-minecraft-1 rcon-cli "tp andy 288 80 -48"
```

### Send Commands to Andy
```bash
cd ~/homelab/mindcraft && docker exec mindcraft-andy node -e "
const io = require('socket.io-client');
const socket = io('http://localhost:8080');
socket.on('connect', () => {
  socket.emit('send-message', 'andy', 'YOUR MESSAGE HERE');
  setTimeout(() => process.exit(0), 2000);
});
"
```

### Restart Services
```bash
# Restart Andy
cd ~/homelab/mindcraft && docker compose restart

# Restart Minecraft server
cd ~/homelab/minecraft && docker compose restart minecraft
```
